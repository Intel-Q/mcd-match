# 麦当劳「消消乐」· 会员互动 Demo

> 🏆 **麦当劳程序员创意开发大赛（M-China 麦当劳开发者创新挑战）参赛作品**
> 赛事官方仓库：<https://github.com/M-China/mcd-developer-innovation-challenge>

**一句话价值**：把会员等餐、餐后的碎片时间，变成一场有麦当劳真实产品陪伴的消消乐——玩得开心、看得见新品，城市榜每周发试吃券，是一个**有人文温度的会员互动 Demo**。

作品内容（产品、真实 kcal 营养数据）在**开发阶段**通过麦当劳 MCP 获取真实数据后融入作品，符合活动「开发时调用 MCP 取内容」的要求；游戏内直接展示 kcal，也让数据来源可被一眼验证。详细取数记录见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。

从技术形态上看，本作品是一个**面向微信小程序场景的 HTML5 单文件消消乐（match-3）**——Demo 阶段以单个 HTML 文件交付，浏览器或直接嵌入小程序 web-view 打开即可运行。

---

## 一、玩法与功能

**核心玩法（消消乐）**

- 8×8 棋盘，点击或滑动交换相邻方块，横 / 竖 ≥3 个相同即消除，连锁掉落补充；
- 手机端支持「点选交换」与「滑动交换」两种手势（Pointer Events 统一处理）；
- 每消除 1 个方块获得「**kcal ÷ 100**」m 币——kcal 为麦当劳 MCP 营养库真实数据；
- 单局 90 秒，倒计时结束自动结算，弹窗展示本局每款产品消除明细与 kcal 汇总。

**会员与赛季机制**

- 每周赛循环：周五 00:00 → 周四 23:59 累计，周四 23:59 冻结进奖池，周五 00:00–23:59 领奖，周五 23:59 未操作清零；
- **防沉迷**：每日最多 50 局、单日 m 币上限 20000；
- **分享有礼（二选一，每日 1 次）**：达到当日限额时可分享，选择「限额翻倍（50→100 局）」或「得 200 m 币」；
- **对战模式**：双人同屏（同设备轮流各 90 秒）、分享邀请朋友异步约战（各自玩 90 秒比 m 币）；对战 m 币同样累计进本周，无论输赢。

**奖池与发券**

- 推广导向券：新品免费试吃券 / 主推套餐买一送一 / 新品第二份半价（前 3 名专属），第 4–100 名得指定新品 8 折入围券；
- **各城市独立排名**，每城前 100 名发券；城市由会员登录授权定位自动确定，无需手动选择；
- 长榜单折叠：只显示**前 10 名 + 我的名次**（中间省略），可点「查看完整榜单」展开全部。

## 三、怎么运行

**零依赖、单文件、双击即玩**：

1. 下载 `mcdonalds_match.html` 到本地；
2. 用任意现代浏览器（Chrome / Safari / Edge）直接打开；
3. 点「▶ 开始游戏」即可。手机端打开同样可用（支持触摸滑动）。

无需安装、无需构建、无需后端、无需任何密钥。

> 备注：Demo 使用 `localStorage` 持久化；在部分隐私 / 沙箱环境下存储会被禁用，此时内存状态照常、仅不落盘，不影响演示。

## 四、使用示例

1. **开局**：点「▶ 开始游戏」→ 90 秒倒计时开始；
2. **消除**：点两个相邻方块交换，或直接滑动某块朝相邻方向划动；≥3 个相同即消除并获得 m 币；
3. **结算**：倒计时归零自动弹窗——本局每款产品消除个数与 kcal、总 kcal、获得 m 币、本周累计；
4. **分享提限**：达到当日 50 局上限后点开始，会提示可分享二选一（限额翻倍 / 200 m 币）；
5. **对战**：「⚔️ 对战」页选双人同屏，或「分享邀请朋友对战」生成邀约海报 / 链接后各自开玩，结束比 m 币；
6. **领奖**：「🎟️ 奖池」页按定位城市看排名，前 100 名可领券或兑积分。

## 五、目标用户

- **参赛评审**：快速把玩完整闭环（游戏 → 分享 → 对战 → 城市榜 → 奖池发券）；
- **麦当劳会员**（成品形态）：等餐陪伴、亲子友好、餐后轻互动，新产品以游戏方块形式自然曝光；
- **运营 / 市场**（成品形态）：方块即推广位，奖池券可配置为新品试吃 / 买一送一等，按城市独立发券。

## 六、生产形态与资源衔接（规划，非本次活动要求）

- **m 币口径**：按固定口径 **10000 m 币 = 1 普通积分** 换算，登录授权后归集麦当劳会员积分体系；
- **优惠券去向**：游戏内兑换的券**自动同步到麦当劳会员小程序「卡包」**，经会员 / 券系统发放到账户，到店核销；
- **产品池刷新**：方块产品由服务端**周期性**调用 MCP 刷新（在售 / 新品 / 活动池），前端不直连 MCP、不持有密钥；
- 游戏只负责「玩法 + 发奖」环节，会员账户与券资产归麦当劳自有体系。
