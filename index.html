🍟 麦当劳「消消乐」会员互动 Demo

一款面向微信小程序场景的 HTML5 单文件消消乐（match-3）。把会员等餐、餐后的碎片时间，变成一场有麦当劳真实产品陪伴的小游戏。

▶ 立即试玩（单文件游戏） 📖 查看项目说明 🏆 赛事官方仓库

这是什么

开发阶段调用 麦当劳 MCP 获取真实营养数据（6 款方块的真实 kcal），游戏内直接展示 kcal，让数据来源可被一眼验证。无需安装、无需后端、无需密钥，双击 HTML 即玩。

8×8 消消乐手机滑动/点选90 秒一局 真实 kcal 计分分享提限双人/异步对战 城市榜试吃券奖池微信小程序场景

核心玩法

  • 消除方块按「kcal ÷ 100」得 m 币，kcal 为麦当劳 MCP 营养库真实字段；
  • 每周赛循环 + 防沉迷限额；分享二选一（限额翻倍 / +200 m 币）；
  • 对战模式：双人同屏或分享邀请朋友异步约战，m 币累计进本周；
  • 各城市独立排名，每城前 100 名发试吃券 / 买一送一券。
本作品为独立开发的参赛 Demo，非麦当劳官方产品，未获品牌背书。游戏内 kcal 仅用于积分换算，不构成营养建议。
